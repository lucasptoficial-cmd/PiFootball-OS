# PiFootball OS v0.1.0-alpha

**Estado:** pré-alpha de desenvolvimento — não é uma imagem instalável.

## Incluído
- Estrutura inicial do projeto baseada em Raspberry Pi OS Lite 32-bit.
- Interface Pygame inicial com navegação por teclado.
- Ecrã de configuração IPTV para host, porta, utilizador e URL M3U.
- Animação de arranque com reflexo verde, logótipo, feixe de luz e transição laranja.
- Demonstração temporária de alerta de golo, acionada com F9 no HOME.

## Limitações conhecidas
- Ainda não existe imagem `.img` nem instalador final.
- Não foi testado num Raspberry Pi 2 físico.
- IPTV ainda não liga nem reproduz canais.
- O alerta de golo é um desenho temporário em Pygame, não um GIF.
- HOME, perfis, som, notificações e restantes módulos continuam em desenvolvimento.

## Requisitos
- Raspberry Pi OS Lite 32-bit como base prevista.
- Python 3 e Pygame para executar o protótipo num ambiente gráfico.

## Aviso
Esta versão destina-se apenas a desenvolvimento e demonstração. Não é uma versão estável nem recomendada para instalação como sistema operativo diário.
